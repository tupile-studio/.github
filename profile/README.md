## Featured project: Bespoke

**An AI-assisted job application workspace, built by Tupile founder Roberto Tomé.**

[Bespoke](https://github.com/rtome85/bespoke) is a browser extension that turns a job posting and a saved profile into tailored CVs and cover letters, with application tracking and interview preparation in the same workspace.

- **Flexible AI integration** — Supports local models through Ollama and multiple cloud providers, with configurable model routing and fallback handling.
- **A complete application workflow** — Job-fit analysis, editable documents, PDF and Markdown exports, application tracking, and interview preparation.
- **Connected tools** — Optional company research and Google Drive backup.

Built with **TypeScript, React, Plasmo, and Tailwind CSS**. The project is maintained in Roberto's personal GitHub account.

**[Explore the source and demo →](https://github.com/rtome85/bespoke)** · **[Chrome Web Store →](https://chromewebstore.google.com/detail/bespoke/fojiljenclkaajpmlhhhepgmlnlllcbd)**
